# CSE422_Project
This project focuses on predicting software quality labels using various Machine Learning and Deep Learning techniques. Using a dataset containing software metrics, the project handles data preprocessing, handles missing values, and implements both supervised and unsupervised learning models to evaluate and compare performance.
Features & Workflow
Data Visualization: Exploratory Data Analysis (EDA) showcasing the distribution of software quality labels.

Data Preprocessing: * Imputation of missing numerical values using SimpleImputer (mean strategy).

Categorical feature encoding using LabelEncoder.

Feature scaling via StandardScaler.

Model Implementation:

Logistic Regression (Supervised Classification)

Naive Bayes (Supervised Classification)

Artificial Neural Network (ANN) (Deep Learning via TensorFlow/Keras)

K-Means Clustering (Unsupervised Learning)

Evaluation Metrics: Comprehensive performance comparison using Accuracy, Weighted F1-Score, Confusion Matrices, and ROC-AUC curves.
